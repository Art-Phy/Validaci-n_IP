# 📘 CHANGELOG

## [1.1.0] - 2025-11-03
### 🚀 Mejoras
- Reescritura completa del validador con estructura modular y funciones documentadas.
- Compatibilidad con **Python 3.10+** y tipado estático (`typing`).
- Incorporación de colores en la terminal usando `colorama`.
- Nuevo modo **interactivo o por argumentos CLI** (`--ip`, `--subnet`).
- Validación más clara para IPs **privadas/públicas** y subredes **CIDR**.
- Manejo mejorado de errores con mensajes visuales y coherentes.
- Código con estilo profesional, limpio y mantenible.

### 🧩 Próximas mejoras (planeadas)
- Añadir validación por rango de IPs.
- Posibilidad de exportar resultados a CSV o JSON.
- Integración en una futura herramienta de red más completa.
